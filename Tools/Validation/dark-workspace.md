This branch keeps Kinovea's C# / WinForms interface and native FFmpeg media engine. Its visual direction is Windows 11 Fluent: neutral charcoal surfaces, Segoe typography, four-pixel rounded controls, eight-pixel pane corners, a light-blue accent, flat menus and cached vector line icons. The command bar exposes Open, Save and Image sequence, with overflow for narrow windows. The browser and viewer have distinct inset panes. Preferences use vertical navigation with a selection marker and keyboard activation. Extraction uses a spacious dark dialog with an accent default action. DWM dark captions and rounded window corners are requested where supported. Controls added after loading receive the theme through events; no theme traversal or animation timer runs during playback.

Geometry follows https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/geometry. This is a Fluent-style native WinForms implementation, not a WinUI migration or Material 3 implementation. Native window frames preserve Windows snapping and resizing. Common dialogs and some native input indicators retain the OS style.

Image sequences now accept an exact frame interval, including every frame and every 15 frames. Single-frame selections are valid, exported-count estimates include the final partial interval, and output dimensions are initialized from the video's reference geometry. Progress notifications are limited to about ten per second. Export failures are logged and shown after playback state is restored. Export still uses the existing modal progress window because its decoder and annotations share player state.

Use File > Save image sequence after opening a video and selecting the working zone. Enter the interval, then save. Use PNG for lossless output. JPEG remains lossy. Output uses reference geometry (which can reflect configured rotation or aspect corrections), with the existing annotation rendering. This change does not introduce proxy previews, concurrent playback during export, or a general-purpose video editor. Existing editing includes drawings, measurements, filters, working-zone selection, and annotated video export.

Run `Tools/Validation/verify-dark-workspace.ps1` on Windows for a standalone compilation and 109 checks against the actual theme, Fluent controls and extraction dialog, plus workspace collapse/restore and settings keyboard/default-action checks. The actual workspace container, settings host and settings navigation also compile in this harness. Media models, preference page content and translated strings are stubbed, so it does not validate decoding, full preference pages or complete application integration.

Pass `-PreviewDirectory <directory>` to render PNG fixtures of the actual extraction dialog, workspace container and settings host. The workspace toolbar/sample viewer and preference-page content are fixtures; these images are not full-application screenshots. Captions are excluded because their appearance is supplied by the host OS. The extraction layout is checked at 100%, 125%, 150% and 200% scales. UI frames render with bounded background fills to avoid clearing sibling controls during offscreen rendering.

Full release validation requires the tools listed in readme.md, NuGet restore, and the native dependencies from Refs/get-dependencies.ps1. The inspected machine has MSBuild, but lacks the .NET Framework 4.8 targeting pack; the checkout also lacks restored NuGet packages and FFmpeg binaries. Full solution compilation and playback benchmarks are therefore pending.
