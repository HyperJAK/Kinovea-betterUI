This branch keeps Kinovea's C# / WinForms interface and native FFmpeg media engine. It adds a shared dark palette, flat buttons and menus, dark window captions on supported Windows versions, roomier application chrome, and a flat timeline with a high-contrast playhead. Controls added after loading receive the theme through events; no theme traversal runs during playback.

Image sequences now accept an exact frame interval, including every frame and every 15 frames. Single-frame selections are valid, exported-count estimates include the final partial interval, and output dimensions are initialized from the video's reference geometry. Progress notifications are limited to about ten per second. Export failures are logged and shown after playback state is restored. Export still uses the existing modal progress window because its decoder and annotations share player state.

Use File > Save image sequence after opening a video and selecting the working zone. Enter the interval, then save. Use PNG for lossless output. JPEG remains lossy. Output uses reference geometry (which can reflect configured rotation or aspect corrections), with the existing annotation rendering. This change does not introduce proxy previews, concurrent playback during export, or a general-purpose video editor. Existing editing includes drawings, measurements, filters, working-zone selection, and annotated video export.

Run `Tools/Validation/verify-dark-workspace.ps1` on Windows for a standalone compilation and 60 checks against the actual theme and extraction dialog. The media models and translated strings are stubbed for this check, so it does not validate the decoder or complete app integration.

Full release validation requires the tools listed in readme.md, NuGet restore, and the native dependencies from Refs/get-dependencies.ps1. The inspected machine has MSBuild, but lacks the .NET Framework 4.8 targeting pack; the checkout also lacks restored NuGet packages and FFmpeg binaries. Full solution compilation and playback benchmarks are therefore pending.

After building, manually verify image loading, video loading, slow motion, single-frame stepping, menus, file browser selection, preferences, color swatches, and annotation readability. Export selections of 1, 2, 16, and 31 frames at intervals 1 and 15; compare the count and image dimensions, then cancel a long export and simulate an unwritable output directory. Test DPI scaling and disabled controls. Some Windows-owned controls and common dialogs still use the OS visual style; this is a native dark theme inspired by modern desktop surfaces rather than a complete Material 3 widget replacement. Zero-lag behavior has not been measured or guaranteed.
